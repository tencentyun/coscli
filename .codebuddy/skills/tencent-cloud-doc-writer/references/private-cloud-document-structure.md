# 腾讯云用户指南文档结构规范

## 文档整体架构

腾讯云用户指南（私有云）采用 **10 大章** 的标准结构，各章节定位与排序如下：

| 序号 | 章节名称 | 定位 | 目标读者 | 核心价值 |
|------|----------|------|----------|----------|
| 1 | 产品简介 | 产品认知建立模块 | 所有用户（含零基础、决策层） | 回答"产品是什么、为什么选、怎么用" |
| 2 | 快速入门 | 低门槛入门流程 | 零基础新手 | 从零到功能可用的最短路径 |
| 3 | 操作指南 | 全场景操作指引 | 全层级用户（新手+老手） | 覆盖全配置选项的步骤化操作 |
| 4 | 最佳实践 | 综合落地场景案例 | 研发/运维/架构师 | 多功能组合的端到端解决方案 |
| 5 | 运维指南 | 实例级日常管理 | 研发工程师/运维人员 | 配置优化、备份、性能调优 |
| 6 | 故障处理 | 实例级问题排查 | 研发工程师/运维人员 | 自助排查与解决方案 |
| 7 | 常见问题 | 高频疑问快速解答 | 全层级客户 | 一问一答式快速查询入口 |
| 8 | 附录A 词汇表 | 术语字典 | 所有用户 | 统一术语认知基准 |
| 9 | 附录B 通用操作 | 跨章节通用操作 | 全层级用户 | 操作复用，避免重复撰写 |
| 10 | 附录C 更多资源 | 信息获取途径 | 所有用户 | 官方平台与联系渠道 |

## 文档头部元信息

```markdown
{产品名称}用户指南

文档版本：{版本号}
发布日期：{YYYY年MM月DD日}
```

## 章节编号规则

- 一级章节：阿拉伯数字（1, 2, 3 ... 10）
- 二级章节：一级号 + 点 + 二级号（1.1, 1.2, 3.4）
- 三级章节：二级号 + 点 + 三级号（3.4.1, 5.2.1）
- 附录章节：附录字母 + 编号（A, B, C）

## 各章节间的关联关系

```
产品简介(1) ──→ 快速入门(2) ──→ 操作指南(3) ──→ 最佳实践(4)
     │                                           │
     ├─→ 相关概念(1.2) ←──── 基础术语支撑 ───────┤
     │                                           │
     ├─→ 监控指标(1.3) ←──── 运维数据支撑 ──→ 运维指南(5)
     │                                           │
     └─→ 与其他云产品关系(1.4) ←── 集成参考 ──→ 故障处理(6)
                                                   │
常见问题(7) ←──────────────────────── 全局问答 ─────┘
                                                    │
词汇表(A) / 通用操作(B) / 更多资源(C) ←── 附录补充 ──┘
```

## 关键区分说明

### 操作指南 vs 快速入门

| 维度 | 操作指南 | 快速入门 |
|------|-----------|----------|
| 目标用户 | 全层级用户 | 仅零基础新手 |
| 核心目标 | 覆盖全场景任务+自定义配置 | 低门槛完成从0到1验证 |
| 写作风格 | 详细严谨，分项说明 | 简洁通俗，给推荐值 |
| 配置深度 | 全量配置选项 | 仅关键配置项 |
| 操作覆盖 | 单任务+批量+多渠道 | 单任务+控制台为主 |

### 用户指南故障处理 vs 底层故障处理手册

| 维度 | 用户指南·故障处理 | 底层故障处理手册 |
|------|-------------------|------------------|
| 面向对象 | 云资源最终使用者 | 云厂商专业运维团队 |
| 聚焦范围 | 实例级问题 | 产品级基础设施问题 |
| 典型场景 | 无法登录、网络不通、磁盘满 | 物理服务器宕机、虚拟化层故障 |
| 解决方式 | 用户自助排查 | 专业工具+权限修复 |

### 用户指南运维指南 vs 底层运维管理手册

| 维度 | 用户指南·运维指南 | 底层运维管理手册 |
|------|-------------------|------------------|
| 面向对象 | 云资源最终使用者 | 云厂商专业运维团队 |
| 聚焦范围 | 实例级日常管理 | 产品级基础设施保障 |
| 典型内容 | 监控告警配置、备份策略 | 物理硬件维护、集群调度 |
