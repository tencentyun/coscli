# 第7章 常见问题 & 附录 写作规范

## 第7章 常见问题（FAQ）

### 定位
高频疑问快速解答模块，面向全层级用户，以**一问一答**极简形式提供直接解决方案。

### 核心原则
| 维度 | 要求 |
|------|------|
| 覆盖范围 | 产品使用中最常问、最易困惑、最易踩坑的问题 |
| 回答限定 | 限定在**用户侧可操作范围**，不涉及底层原理 |
| 内容风格 | 简洁直白、步骤明确、入口清晰 |

### 分类规则
- 按产品功能/使用场景划分二级章节
- 优先覆盖高频问题类型：地域/可用区、实例、存储、网络、监控、计费等

### 写作格式

```markdown
## {二级分类名称}

**Q: {问题名称}**

**A:** {回答内容}
1. {步骤1}
2. {步骤2}
3. {可选的参考文档链接}

---

**Q: {另一个问题}**

**A:** {回答}
```

### 写作要求
- **问题**：简洁直白，直击疑问点，不堆砌专业术语
- **回答**：简短可操作，优先给步骤/入口/链接
- **关联指引**（可选）：复杂问题补充关联文档链接

## 第8章 附录A 词汇表

### 结构要求
按术语名称首字母排序展示：

```
A-E
F-J
K-O
P-T
U-Z
```

每个分类下包含超链接锚点。

### 术语条目格式
```markdown
**{术语名称}**
{术语介绍文字描述}
```

### 排序规则
- 中文术语：按首个汉字拼音排序
- 英文术语：按首字母排序
- 字母分组后可设置超链接跳转至具体术语

## 第9章 附录B 通用操作

### 结构组成

#### 操作场景列表（必选）
表格形式全面覆盖通用操作范围：

| 序号 | 场景类型 | 场景名称 |
|------|----------|----------|
| 01 | 操作类 | {具体操作场景名} |
| 02 | 查找类 | {查找场景名} |
| ... | ... | ... |

表格中的场景名称需支持跳转到对应详细段落。

#### 各操作详细说明
每个操作包含两个子段落：

##### ● 操作描述（必选）
分段落描写：
- **背景**：为什么需要执行该操作
- **目的**：执行后达到什么效果
- **前置条件**：执行前需完成哪些必要操作

##### ● 处理步骤（必选）
详细的处理步骤，需包含：
- 文字描述
- 命令示例
- 截图示例（实际输出时标注位置）
- 表格示例
- 执行结果
- 确保读者可以据此完成实际操作

## 第10章 附录C 更多资源

### 结构组成

#### 自助获取信息途径
- 概要介绍腾讯云官方平台类型及用途
- 每个平台详细描述：
  - 平台名称
  - 平台链接
  - 使用该平台的理由和目的

#### 联系工作人员途径
- 详细介绍需要联系工作人员的场景
- 具体的联系方式（联系电话、官网"联系我们"等）

## 全局写作规范汇总

### 语言规范
1. **语言风格**：专业但不晦涩，通俗但严谨
2. **人称**：使用第二人称"您"
3. **时态**：一般现在时为主
4. **术语一致性**：全文统一术语表达，首次出现附英文全称+缩写

### 格式规范
1. **标题层级**：严格遵循H1/H2/H3层级
2. **列表**：有序列表用于步骤，无序列举用于要点列举
3. **表格**：条件对比、配置选项、指标信息等必须用表格承载
4. **代码块**：命令行代码使用代码块格式，注明语言类型

### 注意事项
1. 私有云产品通常不需要呈现产品刊例价信息；如必需则使用**表格**方式承载，禁止截图
2. 所有价格/规格等结构化数据均采用表格形式
3. 步骤类内容必须使用有序列表
4. 条件/方案类内容必须使用表格
5. 各子段间的操作步骤均从1开头重新编号
