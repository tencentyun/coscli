# 第4章 最佳实践 & 第5/6章 运维/故障处理 写作规范

## 第4章 最佳实践

### 定位
产品功能的**综合落地场景化指引模块**，区别于操作指南的单一功能操作，聚焦**热门业务场景 + 多功能组合整合**，形成端到端的完整业务解决方案。

### 核心特征
| 维度 | 说明 |
|------|------|
| 面向对象 | 研发、运维、架构师（有实际业务部署需求）|
| 内容特点 | 场景概念构建 + 多功能协同落地 |
| 输出形式 | 可配套原理架构/示意图 + 标准化实操步骤 |

### 章节分节逻辑
按场景类型设置二级章节：
1. **通用基础热门场景**（优先）：如搭建Web站点、数据库集群
2. **垂直行业专属场景**：如游戏业务部署、电商高可用
3. **复杂定制化场景**：如跨地域容灾、混合云部署

### 单个案例固定段落体系

| 段落 | 必选/可选 | 核心内容要求 |
|------|-----------|--------------|
| 操作场景（含原理架构）| **必选** | 业务背景+核心需求+架构原理+数据流转逻辑+产品功能组合说明；**核心重点，需详细阐述** |
| 前提条件 | **必选** | 资源、权限、网络等前置要求 |
| 技能要求 | **必选** | 区分新手入门版和进阶定制版的技能要求 |
| 操作步骤 | **必选** | 端到端流程拆解，区分不同版本部署方式，关联操作指南章节 |
| 验证方法 | **必选** | 多维度验证（组件服务/功能/数据交互）|
| 后续优化 | 可选 | 性能/安全/可用性/成本优化方向 |
| 注意事项 | 可选 | 高频坑点、风险点、操作禁忌 |

### 操作场景写作要点

需详细阐述以下内容：

1. **业务适用背景**：什么业务需要这个方案
2. **核心需求**：解决什么痛点问题
3. **架构组成及数据流转**：
   - 底层资源层 → 系统层 → 组件层 的层次结构
   - 数据流转的完整链路（请求→处理→返回）
4. **产品功能组合逻辑**：每个参与的产品/功能及其作用

### 技能要求写作要点
区分两个版本的能力要求：
- **新手入门版**：基础操作能力即可，推荐一键部署方式
- **进阶定制版**：需掌握系统配置、调优能力

> 补充说明：若用户完全无基础，提供低门槛替代方案（如云市场镜像）

### 后续优化分层建议
- **基础优化**（所有用户推荐）：安全加固、性能调优
- **进阶优化**（中小企业推荐）：可用性保障、成本控制
- **高级优化**（大型业务推荐）：架构升级、分布式改造

## 第5章 运维指南

### 定位
面向云资源的最终使用者，聚焦**实例级**的日常管理。

### 与底层运维管理手册的区别

| 维度 | 用户指南·运维指南 | 底层运维管理手册 |
|------|-------------------|------------------|
| 面向 | 资源使用者 | 云厂商运维团队 |
| 范围 | 实例级管理 | 产品级基础设施 |
| 典型内容 | 监控告警配置、备份策略、性能调优 | 物理硬件维护、虚拟化层优化、集群调度 |

### 章节结构
```
5 运维指南
├── 5.1 业务风险提示（同3.1模板）
├── 5.2 配置XXX
│   ├── 操作场景
│   ├── 前提条件
│   ├── 操作步骤
│   ├── 验证方法
│   └── 注意事项（可选）
├── 5.3 备份XXX
└── ...
```

### 运维操作写作规范

#### 操作场景
明确运维的业务背景、适用实例、解决问题、落地价值。限定在**实例级范畴**。

#### 前提条件
- 实例状态、账号权限、已开通服务、资源状态
- 未满足时提供解决方案表格

#### 操作步骤
- 按"进入页面→基础配置→规则设置→关联实例→保存生效"拆解
- 支持控制台为主、API/CLI为辅

#### 验证方法
- 控制台查看策略状态
- 模拟触发验证
- 形成运维闭环

## 第6章 故障处理

### 定位
面向云资源的最终使用者，聚焦**实例级**的问题解决。

### 二级目录分类规则

1. **分类原则**：以「故障现象相似度」为核心聚合依据
2. **命名规范**："XX类故障"格式（如登录类故障、网络连通类故障）
3. **覆盖范围**：全面覆盖高频故障场景，二级目录控制在8-12个
4. **归属规则**：单故障仅归一类，按"核心现象"归类
5. **特殊处理**：跨场景故障归入"核心影响更严重的场景"

### 单故障文档固定段落体系（全部必选）

| 段落 | 写作目的 | 核心内容 |
|------|----------|----------|
| 现象描述 | 还原用户直观感知 | 界面状态+系统提示+报错信息+标准错误码 |
| 可能原因 | 列出排查方向 | 按高频→低频、简单→复杂排序，全量覆盖实例级可查原因 |
| 排查步骤 | 提供Checklist | 从易到难、每步单一验证项、无需专业权限 |
| 解决方案 | 给出修复操作 | 对应原因给出可直接执行的修复步骤 |
| 预防措施 | 规避复发 | 安全配置、监控告警、日常巡检、规范操作 |

### 故障示例结构

```markdown
现象描述
故障现象：{用户看到的表现}，{报错信息}；{业务影响}。

可能原因
1. {最可能的原因}
2. {次可能的原因}
...

排查步骤
1. 检查{项1}：{如何检查}
2. 检查{项2}：{如何检查}
...

解决方案
1. 对应原因1：{具体修复步骤}
2. 对应原因2：{具体修复步骤}
...

预防措施
1. {常态化规避方法1}
2. {常态化规避方法2}
...
```
