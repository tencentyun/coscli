# 写作规则速查

本文档是写作过程中的快速查阅手册。**细则以各权威规范文件为准**，本文档仅提供：
- Markdown 语法映射（各规范没有单独章节）
- 文档类型识别规则（跨文件的路由表）

其他详细规则请直接查阅对应规范文件，避免内容冗余。

---

## 一、Markdown 输出格式（语法映射）

所有输出必须为标准 Markdown 文档，文件扩展名 `.md`。

### 1.1 Markdown 元素映射

| 文档元素 | Markdown 语法 | 示例 |
|---------|-------------|------|
| 标题 | `# ` ~ `#### ` | `# 文档标题`（最多四级） |
| 段落 | 空行分隔 | 正文段落 |
| 引用块 | `> ` | `> 引用内容` |
| 代码块 | ` ```language ` | ` ```python `（必须标注语言） |
| 行内代码 | `` ` `` | `` `kubectl` `` |
| 无序列表 | `- ` | `- 列表项` |
| 有序列表 | `1. ` | `1. 第一步` |
| 表格 | `| 表头 |` | 标准 Markdown 表格 |
| 图片 | `![alt](url)` | `![架构图](https://...)` |
| 超链接 | `[title](url)` | `[云服务器文档](https://...)` |
| 加粗 | `**text**` | `**确定**` |
| 斜体 | `*text*` | `*注意事项*` |
| 删除线 | `~~text~~` | `~~已废弃~~` |
| 说明提示 | `> **说明**：` | `> **说明**：补充信息` |
| 注意提示 | `> **注意**：` | `> **注意**：重要事项` |
| 警告提示 | `> **警告**：` | `> **警告**：危险操作` |
| 禁止提示 | `> **禁止**：` | `> **禁止**：禁用操作` |

### 1.2 Markdown 关键约束（硬性）

1. 标题层级不超过 4 级（`#` ~ `####`），禁止 H5 及以下
2. 代码块必须标注语言类型（`` ```python ``，而非 `` ``` ``）
3. 表格必须有表头，至少 2 行 2 列
4. 界面控件名称加粗：单击 **确定**
5. 操作路径用 ` > ` 连接：**控制台** > **云服务器** > **实例列表**
6. 提示框使用引用块 + 加粗前缀表示

> 详细的界面控件表达、表格、代码、链接等元素格式规范见 `formatting.md`。
