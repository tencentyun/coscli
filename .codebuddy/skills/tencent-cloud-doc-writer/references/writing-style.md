# 腾讯云文档写作风格规范

> 来源：腾讯云产品文档写作规范体系 TAPD Wiki 官方规范（句子规范、段落规范、词汇规范），综合写作指南要求。

---

## 一、写作风格定位

腾讯云技术文档的风格定位：**专业、简洁、客观、友好**。

- **专业**：使用规范的技术术语，表述准确可靠。
- **简洁**：避免冗余表达，直击核心信息。
- **客观**：以事实为基础，避免主观评价和营销性用语。
- **友好**：降低理解门槛，适当解释专业概念。

---

## 二、目标读者分层

写作时根据目标读者调整内容深度：

| 读者类型 | 特征 | 写作策略 |
|---------|------|---------|
| 初学者 | 无技术背景或刚接触云计算 | 更多解释、引导和截图 |
| 开发者 | 具备基本技术素养 | 专注关键信息和代码示例 |
| 运维人员 | 关注部署和运维 | 注重操作步骤和配置参数 |
| 架构师 | 关注方案设计 | 提供架构图和方案对比 |

## 三、语言表达要求（来源：句子规范、词汇规范）

### 1. 人称规范（来源：词汇规范建议3-4）

- 第一人称使用"腾讯云"、"我们"，不使用"小编"、"笔者"等。
- 称呼用户使用"您"或者"用户"，不使用"你"等。
- 描述产品行为时使用产品名称或"系统"作主语。

### 2. 语气规范（来源：段落规范规则4、句子规范规则4）

- 使用陈述和肯定语气，语调客观、正式。
- 描述操作使用祈使句或"可以"句式。
- 避免使用感叹语气。
- 使用直接陈述，避免双重否定和反问句。
- 使用明确的陈述，不使用无意义、犹豫、模棱两可的语言。

### 3. 句子要求（来源：句子规范）

- 一个句子只能有一个主题，且语义表达需完整。
- 简单句不超过50个字，复合句不超过100个字。
- 使用简单句和并列句，避免使用复合句。
- 避免多名词或多形容词修饰方式。
- 句子的主语要明确。
- 句式要保持统一，尤其是并列句。
- 使用主动语态，尽量避免被动语态。

### 4. 词汇要求（来源：词汇规范）

- 禁止使用错别字（包括流行语中的谐音错别字）。
- 避免使用口语化词语。
- 避免使用表示程度、强调语气的词。
- 避免使用可能会引起操作者负面情绪的词语。
- 用词前后一致，禁止使用不同的词汇描述同一事物或操作。
- 举例使用"例如"，不用"比如"。

### 5. 简洁原则

- 删除不必要的修饰词。
- 合并重复信息。
- 用表格替代冗长的段落描述。
- 详细说明放到独立文档，用链接引用。
- 把复杂句改为列表或分拆成简单句。

### 6. 精简对照

| 冗余表述 | 精简表述 |
|---------|---------|
| 在此情况下 | 此时 |
| 在...的时候 | ...时 |
| 为了能够 | 为了 |
| 是否已经完成了 | 是否完成 |
| 需要注意的是 | 注意 |
| 接下来将会 | 接下来 |
| 此外还需要 | 还需 |

---

## 四、段落要求（来源：段落规范）

- 一个段落只能有一个主题，或一个中心句子。
- 段落的中心句子放在段首，后面句子为核心句服务。
- 一个段落的长度不能超过7行，最佳段落长度≤4行。
- 文章第一段的介绍性文字应简短。
- 技术描述类主题，先图表后句子。
- 不出现连续3个以上的纯文字段落，通过图、表等方式避免文字描述的单一性。

## 五、篇幅控制

### 各文档类型推荐篇幅

| 文档类型 | 推荐篇幅 | 说明 |
|---------|---------|------|
| 产品简介 | 800～1500 字 | 概述性内容 |
| 购买指南 | 1000～2000 字 | 视计费模式复杂度 |
| 快速入门 | 800～1500 字 | 简洁为主 |
| 操作指南 | 500～1500 字/篇 | 每篇聚焦单一操作 |
| 最佳实践 | 1500～3000 字 | 视方案复杂度 |
| 常见问题 | 100～300 字/题 | 简洁直接 |
| API 文档 | 按接口标准 | 结构化内容 |
| 故障排查 | 500～1500 字/篇 | 一个问题一篇 |

## 六、文档质量检查清单

### 内容质量

- [ ] 内容准确，技术细节经过验证
- [ ] 步骤完整，用户可按步骤操作成功
- [ ] 前置条件和依赖关系说明清楚
- [ ] 无过时信息，版本号和参数正确
- [ ] 操作完成后有方法检查或验证操作是否成功

### 语言质量

- [ ] 第一人称使用"腾讯云"或"我们"，未使用"小编""笔者"
- [ ] 称呼用户使用"您"或"用户"，未使用"你"
- [ ] 无感叹语气
- [ ] 无口语化词语
- [ ] 无表示程度/强调语气的词
- [ ] 句子简短（简单句≤50字，复合句≤100字）
- [ ] 使用主动语态，避免被动语态
- [ ] 术语使用统一规范
- [ ] 使用"账号"而非"帐号"
- [ ] 举例使用"例如"而非"比如"

### 格式质量

- [ ] 标题简洁扼要，不超过15个汉字
- [ ] 同级标题结构一致
- [ ] 汉字与英文之间有空格
- [ ] 数字与汉字之间无空格
- [ ] 数字与单位之间无空格
- [ ] 数学运算/关系符号前后有空格
- [ ] 键盘快捷键"+"前后无空格
- [ ] 链接与正文汉字之间有空格
- [ ] 界面控件名称使用加粗
- [ ] 连续界面操作使用" > "连接，前后加空格
- [ ] 代码块与正文分开，内联代码使用反引号
- [ ] 表格至少2行2列，有表头
- [ ] 列表嵌套≤1层
- [ ] 内容引用使用"请参见"
- [ ] 图片敏感信息已打码
- [ ] 链接可访问，有标题
- [ ] 时间使用半角冒号（如18:00而非18：00）
- [ ] 货币符号与金额之间不留空格（如¥1,234.56）
