> 来源：腾讯云产品文档写作规范体系 TAPD Wiki 官方规范（词汇规范）及腾讯云产品命名规范。

## 1. 产品名称规范

### 1.1 使用规则

- 首次出现：使用中文全称 + 英文全称 + 缩写。
- 后续出现：可使用缩写。
- 产品名称以官方定义为准，不得随意缩写或更改。
- 标题中直接使用缩略语，不需要全称。

**格式**：`中文名称（英文名称，缩写）`

举例：云服务器（Cloud Virtual Machine，CVM）为您提供安全可靠的弹性计算服务。

## 2. 通用术语规范

### 2.1 易混淆字词（来源：词汇规范）

| 推荐用词 | 避免用词 | 说明 |
|---------|---------|------|
| 登录 | 登陆 | "登录"是正确的计算机术语 |
| 单击 | 点击 | 统一使用"单击" |
| 其他 | 其它 | "其他"是推荐写法 |
| 账号 | 帐号 | 国家语言文字工作委员会要求统一使用"账号" |
| 账户 | 帐户 | 统一使用"账户" |
| 部署 | 布署 | "部署"是正确写法 |
| 例如 | 比如 | 技术文档中使用"例如" |

### 2.2 人称用词规范（来源：词汇规范建议3-4）

| 场景 | 推荐用词 | 避免用词 |
|------|---------|---------|
| 第一人称 | "腾讯云"、"我们" | "小编"、"笔者" |
| 称呼用户 | "您"或"用户" | "你" |

### 2.3 避免使用的词语（来源：词汇规范规则2-4）

**口语化词语（禁止使用）**：
- "不准"、"……的话"、"就可以了"、"干……用"、"么"、"喔"、"挂掉"等

**表示程度/强调语气的词（避免使用）**：
- 表示程度的词：较多、较好、完全地、基本地、决定性的、最后的、仅仅、事实上、值得注意的
- 表示转折的词：当然
- 表示量的词：有些、非常、大量、一些、少许

**负面情绪词语（避免使用）**：
- "杀死"、"踢出"等可能引起操作者负面情绪的词语
- 反例："进程被杀死"、"你已被踢出"

**宗教、政治导向词语（禁止使用）**

**法律法规严禁词汇（禁止使用）**

### 2.4 用词一致性原则（来源：词汇规范规则5-6）

- 用词前后一致，禁止使用不同的词汇描述同一事物或操作。

正例：前面使用了"本地 PC"，后面不再使用"电脑"来描述。

- 相邻短语词性、结构保持一致。

正例：系统提供数据库管理、权限管理、数据导入等功能。
反例：系统提供数据库管理、权限管理、导入数据等功能。

### 2.5 "的""地""得"用法（来源：词汇规范建议2）

- **"的"**：形容词（代词）+的+名词。用来修饰、限制"的"后面的事物。
- **"地"**：副词+地+动词。用来形容"地"后面的动作。
- **"得"**：动词+得+副词。用来补充说明"得"前面的动作怎么样。

### 2.6 界面操作术语（来源：界面控件规范）

| 术语 | 使用场景 | 示例 |
|------|---------|------|
| 单击 | 鼠标操作 | 单击**确定** |
| 双击 | 鼠标双击 | 双击应用图标 |
| 右键单击 | 右键菜单 | 右键单击实例名称 |
| 选择 | 下拉菜单/导航 | 选择**云服务器** |
| 输入 | 文本输入 | 输入实例名称 |
| 勾选 | 复选框 | 勾选**同意协议** |
| 切换 | 选项卡 | 切换到**安全组**页签 |
| 展开 | 折叠面板 | 展开**高级设置** |

## 3. 英文术语规范

### 3.1 大小写规则

- 产品名称首字母大写：Cloud Virtual Machine
- 缩写全大写：CVM、API、SDK
- 协议名称全大写：HTTP、HTTPS、TCP、UDP
- 编程语言首字母大写：Python、Java、Go
- 操作系统按官方写法：Linux、Windows、macOS

### 3.2 常见缩写

| 缩写 | 全称 | 说明 |
|------|------|------|
| API | Application Programming Interface | 应用程序接口 |
| SDK | Software Development Kit | 软件开发工具包 |
| CLI | Command Line Interface | 命令行界面 |
| IAM | Identity and Access Management | 身份与访问管理 |
| SLA | Service Level Agreement | 服务等级协议 |
| QPS | Queries Per Second | 每秒查询数 |
| TPS | Transactions Per Second | 每秒事务数 |
| EIP | Elastic IP | 弹性公网 IP |
| ENI | Elastic Network Interface | 弹性网卡 |

### 3.3 不翻译的术语

以下术语保持英文原文，不进行翻译：
- Kubernetes（不翻译为"库伯内特斯"）
- Docker（不翻译为"多克"）
- Nginx（不翻译为"恩金克斯"）
- Redis（不翻译）
- MySQL（不翻译）
- Linux（不翻译）
- Token（可使用"令牌"，视场景）

## 4. 版本号和日期

### 4.1 版本号格式

- 完整版本号：v1.0.0
- 主版本号：v1
- API 版本：2021-03-23

### 4.2 日期和时间格式（来源：数及数量规范规则10）

**日期**：
- 在表格、索引、年表中：YYYY-MM-DD（如 2024-01-15），月和日为个位数时加"0"补充。
- 在描述性的内容中：YYYY年MM月DD日（如 2024年1月15日）。

**时间**：
- 按照GB/T 7408-2005要求：XX:XX:XX（使用半角冒号，如 14:30:00）。
- 正文中可表示为：XX时XX分XX秒。

**日期和时间组合**：YYYY-MM-DD hh:mm:ss（如 2024-01-15 14:30:00）。

## 5. 错误信息和状态

### 5.1 HTTP 状态码

| 状态码 | 含义 |
|-------|------|
| 200 | 成功 |
| 400 | 请求参数错误 |
| 401 | 未授权 |
| 403 | 禁止访问 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

### 5.2 实例状态

| 状态 | 说明 |
|------|------|
| Running | 运行中 |
| Stopped | 已停止 |
| Starting | 启动中 |
| Stopping | 停止中 |
| Creating | 创建中 |
| Deleting | 删除中 |
