# tencent-cloud-doc-writer Skill 使用说明

这是一个[腾讯写写](https://write.woa.com/) Skill，让 AI 助手具备两大能力：

**A. 写文档** — 按腾讯云文档写作规范（26 项子规范 + 17 套模板）生成标准 Markdown 文档，支持公有云和私有云（用户指南）两种场景

**B. 操作文档系统** — 通过 API 查询项目、读写文档、上传图片、管理目录树，将文档推送到腾讯云写写系统

## 安装

将 `tencent-cloud-doc-writer` 目录放到你项目根目录的 `skills/` 下即可，CodeBuddy 会自动识别。

## 配置

使用"操作文档系统"功能前，需配置一个环境变量：

```bash
export AI_WRITE_API_TOKEN="你的Token"
```

### 如何获取 Token

1. 打开 <https://tai.it.woa.com/user/pat>
2. 点击「创建个人令牌」
3. 「授权应用」选择 **腾讯写写**
4. 点击「确认」，复制生成的 Token

配置好后，可直接告诉 CodeBuddy：`我的 AI_WRITE_API_TOKEN 是 xxx`，CodeBuddy 会帮你写入环境变量。

> API 地址 `https://write.mcp.it.woa.com` 已内置，无需配置。

## 使用方式

安装并配置好环境变量后，在 CodeBuddy 中用自然语言对话即可。下面按使用场景分组说明。

### 1. 生成文档

告诉 AI 你想写什么文档，**注意说明是公有云还是私有云场景**：

```
帮我写一篇公有云的云服务器产品简介
写一个公有云云数据库的快速入门文档
帮我写个 API 文档，接口是"创建实例"
帮我写私有云 TKE 的操作指南
写一篇私有化部署 TDSQL 的最佳实践
```

> **公有云 vs 私有云**：面向公网用户、按量/包年包月售卖的是公有云；部署在客户机房、整体交付的是私有云（用户指南形式）。不确定时直接问 AI。

### 2. 查看已有内容

```
查一下我的项目列表
看看项目 78595548379652096 里有哪些文档
帮我找一下"购买指南"这篇文档的内容
```

> **项目 ID 怎么看**：在写写系统页面 URL 中能看到；或直接让 AI 查"我的项目列表"，会返回带 ID 的列表。

### 3. 修改已有文档

```
把文档 78595548379652100 的标题改成"快速入门"
修改这篇文档的第二段，改成 xxx
```

### 4. 创建新文档并保存

```
在项目 78595548379652096 下新建一篇"快速入门"文档
帮我在"操作指南"下面新建一篇"创建实例"的文档
```

AI 会先生成 Markdown 内容，再自动保存到文档系统。

### 5. 推送本地 Markdown 到文档系统

```
把 快速入门.md 推送到文档 78595548379652100，追加到末尾
把 快速入门.md 推送到文档 78595548379652100，直接覆盖原文
```

> ⚠️ **重要**：推送时必须**显式指明「追加」或「覆盖」**。如果不指明，AI 默认会覆盖原文，可能造成数据丢失！

### 6. 在指定版本下操作

当项目有多个版本（例如v1.0/v2.0 版本）时，对话中直接说出版本名称即可：

```
看看项目 78595548379652096 的英文版有哪些文档
在项目 78595548379652096 的 v2.0 版本下新建一篇文档
查一下项目 X 有哪些版本
```

AI 会自动获取版本列表、匹配目标版本，后续操作都在该版本下进行。不指定版本时自动使用默认版本。
> ⚠️ **重要**：不支持推送或删除非中文的多语言版本内容。

### 7. 图片自动上传

当你要保存或推送的 Markdown 中包含**本地图片引用**（如 `![封面](./images/cover.png)`）时，Skill 会自动把这些图片上传到写写系统，并把 Markdown 中的本地路径替换为系统中的路径，无需任何手动操作。

示例：

```
把 快速入门.md 推送到文档 78595548379652100，追加到末尾
```

如果 `快速入门.md` 里写了 `![示意图](./images/demo.png)`，Skill 会自动：
1. 上传 `./images/demo.png` 到写写系统
2. 把 Markdown 中的 `./images/demo.png` 替换成系统图片路径
3. 推送最终的 Markdown 到目标文档

### 8. 调整目录顺序

```
把"快速入门"移到"产品简介"下面
调整一下项目 78595548379652096 的目录顺序
```

### 9. 迭代调整

文档生成/修改后，可以继续对 AI 说：

```
第二章写得太啰嗦，精简一下
把"注意事项"那一节单独拆成一个小节
调整整体语气，更正式一些
```

## 常见问题

**Q：Token 从哪里获取？**

打开 <https://tai.it.woa.com/user/pat>，点「创建个人令牌」→ 「授权应用」选择「腾讯写写」→ 确认，复制生成的 Token 填入环境变量 `AI_WRITE_API_TOKEN` 即可。

**Q：项目 ID / 文档 ID 在哪里看？**

- 在写写系统页面的 URL 中可以看到
- 或直接让 AI 查"我的项目列表"，会返回带 ID 的项目列表

**Q：项目有多个版本怎么操作？**

在对话中直接说出版本名称即可（如"英文版"、"v2.0"）。AI 会自动查询版本列表并匹配；不指定版本时使用默认版本。

**Q：文档里有图片怎么办？**

在 Markdown 中正常写本地图片引用（如 `![封面](./images/cover.png)`）即可。保存或推送时，Skill 会自动把本地图片上传到写写系统，并替换为系统路径，无需手动处理。

**Q：推送已有 Markdown 时怎么避免覆盖原文？**

推送时**一定要在对话中显式说明**「追加到末尾」或「覆盖原文」。不说明的话 AI 会默认覆盖，可能导致数据丢失。

**Q：生成的文档不满意怎么办？**

直接在对话中说出要修改的部分即可，如"第二章精简一下""补充一下注意事项"，AI 会在当前文档上继续迭代。

**Q：公有云和私有云文档有什么区别？**

公有云文档按**单篇独立**结构撰写；私有云文档以**整本用户指南**形式交付，采用 10 大章标准架构（产品简介 → 快速入门 → 操作指南 → 最佳实践 → 运维指南 → 故障处理 → 常见问题 → 词汇表 → 通用操作 → 更多资源）。如果分不清你的场景，直接问 AI。
