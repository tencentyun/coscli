# 参数说明模板

> 参数说明写作规范请参见 `references/doc-types.md` > 四、参数类文档写作规范。

---

## 模板结构

```
# [参数文档标题]

## [模块一]参数说明

| 名称 | 含义 | 类型 | 必填 | 取值范围 | 备注 |
|------|------|------|------|---------|------|
| [参数名] | [参数定义] | [数据类型] | [是/否] | [取值范围，含默认值] | [备注或"-"] |

## [模块二]参数说明

| 名称 | 含义 | 类型 | 必填 | 取值范围 | 备注 |
|------|------|------|------|---------|------|
| [参数名] | [参数定义] | [数据类型] | [是/否] | [取值范围，含默认值] | [备注或"-"] |
```

---

## 字段说明

| 字段 | 说明 |
|------|------|
| **名称** | 填写参数名称，例如 Region |
| **含义** | 填写参数定义，例如"地域" |
| **类型** | 参数的数据类型，例如 String、Integer、Boolean、Array 等 |
| **必填** | 填写"是"或"否"。如果该参数是必选参数，则填"是"，反之为"否" |
| **取值范围** | 参数的取值范围，例如 ap-bangkok、ap-beijing 等。有默认值需要写明默认值 |
| **备注** | 补充参数的信息，有则填写，无则写"-"。例如说明该参数与某参数关联使用、该参数仅在某场景使用、生效条件等 |

---

## 完整示例

```
# 地域和可用区参数说明

## 地域参数说明

| 名称 | 含义 | 类型 | 必填 | 取值范围 | 备注 |
|------|------|------|------|---------|------|
| Region | 地域 | String | 是 | ap-bangkok、ap-beijing、ap-chengdu、ap-guangzhou、ap-shanghai 等 | - |

## 实例参数说明

| 名称 | 含义 | 类型 | 必填 | 取值范围 | 备注 |
|------|------|------|------|---------|------|
| InstanceType | 实例规格 | String | 是 | S5.MEDIUM2、S5.LARGE8 等 | 请参见实例规格文档 |
| ImageId | 镜像 ID | String | 是 | img-xxxx | 仅支持当前地域的镜像 |
| SystemDiskSize | 系统盘大小 | Integer | 否 | 50～500，默认值为50 | 单位：GB |
```
