# 服务等级协议（SLA）模板

> 本文档旨在规范《服务等级协议（SLA）》文档的合规性和统一性。SLA 文档需经法务审核后方可发布。

---

## 模板结构

SLA 根据产品是否收费分为两种模板：

### 收费产品 SLA 模板

```
# [产品名称]服务等级协议

**最近更新时间：[YYYY-MM-DD]**

## 1. 服务内容

[简要描述产品提供的服务内容]

## 2. 服务可用性

### 2.1 服务可用性计算方式

服务可用性 = (1 - 服务不可用时间 / 服务总时间) × 100%

### 2.2 服务可用性标准

| 服务 | 服务可用性 |
|------|----------|
| [产品名称] | [≥ XX.XX%] |

### 2.3 服务不可用的定义

[定义在什么情况下视为服务不可用]

### 2.4 服务不可用时间的排除

以下情况不计入服务不可用时间：
- 腾讯云预先通知用户的系统维护。
- 用户侧原因导致的服务不可用。
- 不可抗力因素导致的服务不可用。
- [其他排除情况]

## 3. 赔偿方案

### 3.1 赔偿标准

| 服务可用性 | 赔偿代金券金额 |
|----------|-------------|
| [≥ XX% 且 < XX%] | 月度服务费的 [XX]% |
| [< XX%] | 月度服务费的 [XX]% |

### 3.2 赔偿申请

- 赔偿申请时限：[服务不可用事件结束后的 XX 个工作日内]
- 赔偿申请方式：[提交工单/联系客服]

## 4. 免责条款

以下情况腾讯云不承担赔偿责任：
- [免责条款一]
- [免责条款二]

## 5. 其他

- 腾讯云有权对本协议进行修改。
- 本协议自发布之日起生效。
```

### 免费产品 SLA 模板

```
# [产品名称]服务等级协议

**最近更新时间：[YYYY-MM-DD]**

## 1. 服务内容

[简要描述产品提供的服务内容]

## 2. 服务可用性

[描述服务可用性目标，但不承诺赔偿]

## 3. 免责条款

[免责说明]

## 4. 其他

[其他条款]
```

---

## 注意事项

- SLA 内容需提交给接口法务进行审核。
- SLA 审批及发布流程需按公司规定执行。
- 已上线产品的服务协议变更/上线，需提前周知客户，请参见腾讯云客户消息推送指引。
