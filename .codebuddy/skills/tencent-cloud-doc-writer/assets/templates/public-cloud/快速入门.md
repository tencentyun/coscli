# 快速入门模板

> 写作要求参考操作类文档写作规范（`references/doc-types.md` > 三、操作类文档写作规范）。
> 来源：快速入门模板（公有云官网平台需求）。
> 《快速入门》文档旨在帮助用户在初期使用产品时，快速搭建基础环境并验证核心功能，以了解产品核心能力和使用流程，降低学习门槛。

---

## 写作规范要求

1. **用户视角优先**：避免技术术语堆砌，例如建议使用"创建实例"而非"实例化一个计算节点"。
2. **场景化导向**：以新手用户场景（如"搭建网站""部署 AI 模型"）为主体，Step by Step 呈现必要操作，复杂操作需拆分为子步骤。高级配置可提供参考链接，作为可选步骤。
3. **目标导向**：用户通过文档能在30分钟内完成核心场景验证。
4. **安全限制**：高危操作禁止写入《快速入门》文档。例如删除资源、重装系统。

---

## 写作要点

1. **文档标题**：初始化服务/XX 快速入门。例如"Go SDK 快速入门""连接 PostgreSQL 实例"。
2. **场景描述在文档起始位置承载**，小标题可选，以正文字体表述，简明扼要。
3. **核心步骤标题样式**：使用"步骤一：XXX""步骤二：XXX"作为二级标题。
4. **代码示例要求**：选择正确代码语言类型，提供必要代码注释和参数说明表。
5. **可根据实际产品特性调整模块顺序**（如 AI 类产品需增加数据准备、模型训练步骤）。
6. **准备工作必须穷举**：账号、资源、权限、其他依赖，缺一不可。

## 完整示例：连接 PostgreSQL 实例

```
# 连接 PostgreSQL 实例

本文为您介绍使用 Windows 操作系统的 CVM，安装标准的 SQL 客户端并通过内网地址连接到云数据库 PostgreSQL 的操作教程。

## 准备工作

- 已注册腾讯云账号并完成实名认证。
  - 如需注册腾讯云账号：请单击注册腾讯云账号。
  - 如需完成实名认证：请单击实名认证。
- 已创建 PostgreSQL 实例。具体操作，请参见云数据库 PostgreSQL 创建 PostgreSQL 实例。

## 操作步骤

1. 登录 Windows 云服务器或本地服务器，下载并安装标准的 SQL 客户端。
   本文以 pgAdmin 为例，您可根据自己的系统下载适配版本的安装程序。前往下载。
2. 打开 pgAdmin，在上方菜单栏选择 **Object** > **Create** > **Server**。
3. 在弹出的 **Create - Server** 对话框，在顶部菜单选择 **Connection**，填写名称、主机 IP 地址、端口号、用户名和密码等后，单击 **Save**。
   - 主机 IP 地址和端口号：可前往 PostgreSQL 控制台，在实例详情页中查看内网地址。

   > 说明：这里的内网地址为 VIP，是通过接入网关集群统一访问数据库实例，而非直接连接到数据库实例物理机上，因此当主机发生故障或主备切换时，内网 IP 都不会变化。

   - 用户名和密码：使用初始化实例时设置的数据库管理员用户名与密码。如忘记密码，可至 PostgreSQL 控制台的账号管理页重置密码。
4. 登录数据库后，在左侧导航选择 **Databases** > **postgres**，即可看到已完成连接的数据库实例信息。
```
