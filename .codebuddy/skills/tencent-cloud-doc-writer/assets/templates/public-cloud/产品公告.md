# 产品公告模板

> 本模板为腾讯云产品公告的标准写作模板。

---

## 模板结构

```
# [产品名称]产品公告

以下为[产品名称]的近期公告，请您关注。更多公告，请参见服务公告。

## [公告标题]

**发布日期**：[YYYY-MM-DD]

[公告正文内容]
```

---

## 写作规范

### 标题要求

- 公告标题格式：`【产品名称】【发布日期】 公告主题`
- 示例：【数据传输服务】【2025年08月22日】 部分接口鉴权升级公告

### 发布日期

- 格式：`YYYY-MM-DD`
- 示例：2025-08-22

### 正文要求

- 说明公告的背景和原因
- 说明变更的具体内容
- 说明对用户的影响
- 提供用户需要采取的操作（如有）
- 提供生效时间

---

## 完整示例

```
# 消息队列 CKafka 产品公告

以下为消息队列 CKafka 的近期公告，请您关注。更多公告，请参见服务公告。

## 【消息队列 CKafka】【2025年09月15日】 实例规格调整公告

**发布日期**：2025-09-15

尊敬的腾讯云用户，您好！

为了提升消息队列 CKafka 的服务质量，腾讯云将于2025年10月01日起对部分实例规格进行调整。

### 变更内容

- 标准版实例最低配置由 40MB/s 调整为 60MB/s。
- 专业版实例新增 200MB/s 和 400MB/s 规格。

### 影响范围

本次调整仅影响新购实例，存量实例不受影响。

### 用户操作

如需升级存量实例规格，请登录消息队列 CKafka 控制台进行操作。

如有疑问，请联系腾讯云售后支持。
```
