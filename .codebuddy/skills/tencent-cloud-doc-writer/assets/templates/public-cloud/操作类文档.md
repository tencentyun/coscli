## 完整示例：SSH 登录 Linux 云服务器

```
# SSH 登录 Linux 云服务器

## 操作场景

该任务指导您在购买并启动云服务器后，在本地 Windows 计算机上通过远程登录软件，登录 Linux 云服务器。登录后，您可以在云服务器上安装您需要的软件。

## 对系统影响

无

## 前提条件

- 已购买并启动 Linux 云服务器。
- Linux 云服务器实例有公网 IP。
- 已获取 Linux 云服务器的管理员帐号和密码。

## 操作步骤

1. 在本地 Windows 计算机上安装远程登录软件，例如 PuTTY。
2. 安装完成后，打开 PuTTY 客户端，在 PuTTY Configuration 窗口中配置如下信息。
   - Host Name：云服务器的公网 IP 地址。公网 IP 地址获取方式：登录云服务器控制台，可在列表页及详情页中进行查看。
   - Port：云服务器的端口，必须填 22。请确保云服务器 22 端口已开放，具体操作请参见安全组及网络 ACL。
   - Connect type：选择 **SSH**。
3. 配置完成后，单击 **Open**，创建一个新对话。
4. 在 PuTTY 会话窗口中，输入前提条件中获得的管理员帐号，按回车键。再输入前提条件中获取的登录密码，回车完成登录过程。

> 注意：如果登录失败，请检查您的云服务器实例是否允许 22 端口的入流量。端口的查看请参见安全组，若您的云服务器处于私有网络环境下，请同时查看相关子网的网络 ACL。

## 相关操作

- WebShell 登录 Linux 云服务器
- VNC 登录 Linux 云服务器
- 密钥登录 Linux 云服务器

## 附录

| 实例操作系统 | 管理员帐号 |
|------------|----------|
| SUSE/CentOS/Debian | root |
| Ubuntu | ubuntu |
```
