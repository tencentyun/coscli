# API 文档模板

> 写作要求参考参数类文档写作规范（`references/doc-types.md` > 四、参数类文档写作规范）。API 文档体系包含多个子文档，本模板定义了完整的子文档结构。

---

## API 文档体系

一套完整的 API 文档通常包含以下子文档：

| 子文档 | 说明 |
|-------|------|
| **更新历史** | 记录 API 版本更新内容 |
| **API 概览** | 汇总所有 API 接口列表 |
| **接口文档**（每个接口一篇） | 单个 API 接口的详细说明 |
| **数据结构** | 公共数据结构定义 |
| **错误码** | 公共错误码和业务错误码 |
| **状态码** | HTTP 状态码和业务状态码（如适用） |

---
