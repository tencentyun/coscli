## 适用场景

本模板适用于**私有云用户指南**中的"产品简介"章节（第1章），涵盖产品概述、相关概念、监控指标、应用场景等内容。与公有云产品简介模板不同，私有云模板：
- 面向私有化部署场景，文档以用户指南形式整体交付
- 包含更详细的监控指标和异常阈值参考
- 包含相关概念（术语字典）作为内置章节
- 有文档版本号和发布日期元信息

## 各段落写作规则详解

### 产品定义与核心价值 — 必选

**内容规则**：
1. 产品名称首次出现必须包含全称+简称+英文缩写，例如：云服务器（Cloud Virtual Machine，CVM）
2. 明确产品的 IaaS/PaaS/SaaS 级别和服务类型
3. 用一句话描述核心功能，一句话描述核心价值或类比

### 前置知识铺垫 — 可选

**内容规则**：
- 以问句形式列出用户阅读前可能需要了解的概念
- 帮助零基础用户判断是否需要先补充知识

### 核心优势 — 必选

**内容规则**：
1. 标题简洁且能概括优势
2. 每项包含特性描述和用户价值两部分
3. 一般4项左右，避免过多

### 相关概念 — 必选

**内容规则**：
1. 按"基础通用类→核心功能类→关联组件类→易混淆类"顺序组织
2. 每个概念包含：中英文名称、核心定义、关键属性、关联场景
3. 定义使用1-2句通俗语言

### 监控指标 — 可选

**内容规则**：
1. 使用表格列出指标类型、ID、名称、单位、描述、正常范围、异常影响
2. 提供指标查看方式（控制台、云监控、API）
3. 提供异常阈值参考和处理建议表

### 应用场景 — 可选

**内容规则**：
- 每个场景用1-3句话描述核心特征、业务需求和产品适配点
- 内容力求真实具体，避免空泛描述
