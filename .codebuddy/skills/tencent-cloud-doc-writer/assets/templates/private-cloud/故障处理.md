# 故障处理模板（私有云用户指南）

> 写作要求请参见 `references/doc-types.md` > 五、故障类文档写作规范。
> 来源：私有云用户指南第6章模板，面向实例级问题排查，帮助用户快速定位原因、解决问题、避免复发。

---

## 适用场景

本模板适用于**私有云用户指南**中的"故障处理"章节（第6章），面向实例级问题排查。与公有云故障处理模板不同，私有云模板：
- 按故障分类组织（如网络类、存储类、计算类等），形成体系化的故障排查手册
- 每个故障包含完整的"现象描述→可能原因→排查步骤→解决方案→预防措施"五步流程
- 包含预防措施，帮助用户避免同类故障再次发生
- 使用章节编号（6.N.M）形式组织，便于在用户指南中索引

## 模板结构

```
## 6 故障处理

本章定位：面向实例级问题排查，帮助用户快速定位原因、解决问题、避免复发。

### 6.{N} {故障分类名称}类故障

#### 6.{N}.{M} {故障名称}

**现象描述**

故障现象：{用户直观看到的表现}，终端提示"{报错信息}"；{控制台状态描述}，业务影响为{影响范围}。

**可能原因**

1. {最可能的原因1}
2. {次可能的原因2}
3. {可能的原因3}
4. {可能的原因4}
5. {可能的原因5}

**排查步骤**

请按以下顺序逐项排查：

1. **检查{项1}**：确认{检查内容}，判断标准为{标准}。
2. **检查{项2}**：{检查方法}，若出现{结果}则说明{含义}。
3. **检查{项3}**：执行{命令/操作}，查看{输出}。
4. **检查{项4}**：在控制台查看{位置}的{指标/状态}。
5. **检查{项5}**：通过{方式}确认{内容}。

**解决方案**

对应上述每个可能原因：

1. **{原因1}**：{修复操作步骤}
2. **{原因2}**：{修复操作步骤}
3. **{原因3}**：{修复操作步骤}
4. **{原因4}**：{修复操作步骤}
5. **{原因5}**：{修复操作步骤}

**预防措施**

为避免同类故障再次发生，建议：

1. 遵循{规范/原则}，仅{限制条件}。
2. 为资源配置{监控告警}，异常提前通知。
3. 定期{巡检/维护}动作，避免{风险}。
4. 避免{不良操作习惯}，及时{正确做法}。
```

## 写作规则详解

### 故障分类 — 必选

**内容规则**：
- 按故障类型分组（如网络类、存储类、计算类、安全类等）
- 每个分类下可包含多个具体故障

### 现象描述 — 必选

**内容规则**：
1. 描述用户直观看到的表现
2. 包含终端报错信息（使用引号标注）
3. 描述控制台状态
4. 说明业务影响范围

### 可能原因 — 必选

**内容规则**：
1. 按可能性从高到低排列
2. 穷举所有可能原因
3. 同一类型的原因需进行归类

### 排查步骤 — 必选

**内容规则**：
1. 提供有序的排查顺序
2. 每步使用加粗标题标识检查项
3. 包含具体的检查方法和判断标准

### 解决方案 — 必选

**内容规则**：
1. 与可能原因一一对应
2. 提供具体的修复操作步骤
3. 每个方案可独立执行

### 预防措施 — 必选（私有云特有）

**内容规则**：
1. 提供避免同类故障再次发生的建议
2. 涵盖规范遵循、监控告警、定期巡检、操作习惯等维度
3. 建议可操作、可落地
