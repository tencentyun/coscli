# 操作指南模板（私有云用户指南）

> 写作要求参考操作类文档写作规范（`references/doc-types.md` > 三、操作类文档写作规范）。
> 来源：私有云用户指南第3章模板，面向全层级用户覆盖产品全场景任务和全配置选项。

---

## 适用场景

本模板适用于**私有云用户指南**中的"操作指南"章节（第3章），覆盖产品全场景任务和全配置选项。与公有云操作类文档模板不同，私有云模板：
- 包含业务风险提示专用章节，结构化地说明操作对业务的影响
- 每个操作包含完整的验证方法和回退方法
- 按功能特性分组组织操作，形成完整的功能模块文档

## 写作规则详解

### 业务风险提示 — 可选

**内容规则**：
1. 对业务有影响的操作必须提供风险提示
2. 使用引用块格式突出显示
3. 包含操作场景、直接结果、影响范围、影响时长、执行建议

### 操作场景 — 必选

**内容规则**：
- 说明何时需要执行此操作，能达成什么效果

### 前提条件 — 必选

**内容规则**：
1. 穷举所有前置条件
2. 提供"情况-操作方案"表格帮助用户解决前置问题

### 操作步骤 — 必选

**内容规则**：
1. 分步骤子标题组织
2. 每步以动词开头，一步一个动作
3. 参数配置使用表格或详细说明

### 验证方法 — 必选（私有云特有）

**内容规则**：
1. 提供至少一种验证方式
2. 控制台验证为首选方式
3. 描述验证操作步骤和预期成功状态

### 回退方法 — 可选（私有云特有）

**内容规则**：
- 分别描述操作过程中和操作完成后的回退方式

### 后续操作 — 可选

**内容规则**：
- 给出资源创建后可进行的后续操作方向
