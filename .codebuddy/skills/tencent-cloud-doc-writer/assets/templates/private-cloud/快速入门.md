## 适用场景

本模板适用于**私有云用户指南**中的"快速入门"章节（第2章），聚焦"快速创建核心资源 + 验证基础功能"。与公有云快速入门模板不同，私有云模板：
- 面向私有化部署环境，控制台入口和操作路径可能与公有云不同
- 前提条件中可能包含私有云特有的环境要求（如内网访问、私有化平台登录）
- 未满足前提条件时提供结构化的解决方案表格

## 写作规则详解

### 操作场景 — 必选

**内容规则**：
1. 用1-2句话说明业务场景和操作目标
2. 明确告知用户通过本文档可以完成什么

### 前提条件 — 必选

**内容规则**：
1. 穷举所有前置条件，使用"已..."句式
2. 可选条件需标注"（可选）"
3. **私有云特有**：未满足前提条件时，提供结构化的"情况-操作方案"表格，帮助用户快速解决前置问题

### 操作步骤 — 必选

**内容规则**：
1. 使用"步骤N：{步骤名称}"作为子标题
2. 每步以动词开头，一步一个动作
3. 包含控制台路径的操作需给出完整导航路径
4. 界面控件名称使用加粗标识
